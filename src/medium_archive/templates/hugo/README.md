# A Hugo blog

Generated by `medium-archive hugo` from an archived Medium publication.
Self-contained: posts as Markdown with YAML front matter in leaf
bundles, and the theme under `layouts/`. No Hugo modules.

## Build

```sh
hugo                          # build into public/
pagefind --site public        # search index for /search/
hugo server                   # serve at localhost:1313
```

Requires Hugo extended 0.156 or newer. `pagefind` (`npm install -g
pagefind`) is needed for search results.

## What to edit

| file | contents |
|------|----------|
| `config/_default/params.toml` | masthead, banner, footer, newsletter, share image, handle and profiles |
| `config/_default/hugo.toml` | `baseURL`, title, language; taxonomies, related posts, paginator, Goldmark, Chroma |
| `content/_index.md` | landing-page blurb |
| `data/tags.yaml` | tag slug → display name |
| `data/authors.yaml` | author slug → display name and optional profile URL |
| `content/posts/<year>/<slug>/index.md` | posts, with their images beside them |
| `layouts/`, `static/`, `assets/` | templates, stylesheet, site images |

Set `baseURL` to the real domain: feeds, redirect stubs, Open Graph tags
and share links are built from it.

## Write a post

```
content/posts/2026/a-new-post/
  index.md
  images/diagram.png
```

```markdown
---
title: A new post
date: '2026-01-31T09:00:00Z'
authors:
- ada-lovelace
tags:
- jupyter
subtitle: The line under the title, Markdown
description: Card excerpt and meta description
cover: images/cover.jpg
---

The body, as Markdown.

![a diagram](images/diagram.png)
```

- The URL is `/posts/<year of date>/<directory>/`. `/posts/<year>/`
  lists that year's posts automatically.
- `authors` and `tags` are slugs; names come from the data files, or
  the slug is shown.
- `lastmod:` sets the sitemap's last-modified date.
- `cover:` is the card and share image; any size.
- Photographs get a responsive `srcset`; png and webp are treated as
  line art and served at full resolution.
- Captioned image:
  `{{< figure src="..." alt="..." >}}the caption{{< /figure >}}`.
- `aliases:` lists old paths to redirect here.

## Regenerating

`medium-archive hugo` overwrites the files it generates and leaves
others alone. While the site is still generated, make corrections in the
archive (`site/site.toml`, `archive/tags.json`, the post). Once this
directory is its own repository (`medium-archive hugo --out DIR`;
`--clean` removes pages the archive no longer has, keeping `.git/` and
ignored files), edit the files here.
